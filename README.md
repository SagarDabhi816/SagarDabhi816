## ChatGPT Clone

**Full-stack AI conversational application with real-time messaging and context-aware chat.**

A ChatGPT-like application built with a React frontend and Node.js backend. It integrates Google's Gemini API for AI-generated responses and uses vector embeddings with Pinecone to support contextual conversations.

**Highlights**

- User authentication and authorization with protected routes.
- Real-time AI messaging powered by Socket.IO.
- Google Gemini API integration for generated responses.
- Context retrieval using embeddings and Pinecone vector database.
- Persistent chat history stored in MongoDB.
- Responsive chat interface and client-server architecture.

**Tech Stack**

`React` `Vite` `Redux Toolkit` `Node.js` `Express.js` `MongoDB` `Mongoose` `Socket.IO` `JWT` `Gemini API` `Pinecone` `Tailwind CSS`

** Links**

-  [Source Code](https://github.com/SagarDabhi816/Chatgpt-clone)

> This project is for learning purposes. A public live demo is not currently provided because of the limited free-tier quota of AI services. Screenshots and source code are available in the repository.
